# Patterns that must never appear in this public repo. One extended regex per
# line; blank lines and # comments ignored.
#
# The threat is not a leaked credential — standards contain none by nature. It
# is leakage by example: the nearest source of a worked example is a private
# homelab, and a config snippet pasted from it publishes real topology.
#
# Placeholders to use instead: example.internal, service-a, 10.0.0.0/8,
# 192.0.2.0/24 (TEST-NET-1), /srv/appdata/<service>.

# Real domains
askpak\.net
xeroip\.(net|dev)

# RFC1918 addresses. 10.0.0.0/8 and 192.0.2.x are allowed as documentation
# ranges; a specific host inside a real private range is not.
192\.168\.[0-9]{1,3}\.[0-9]{1,3}
172\.(1[6-9]|2[0-9]|3[01])\.[0-9]{1,3}\.[0-9]{1,3}

# Live host and service names
\bTower\b
\bpapa[-_]pedro\b

# Credential shapes
-----BEGIN [A-Z ]*PRIVATE KEY-----
\bgh[pousr]_[A-Za-z0-9]{20,}
\bAKIA[0-9A-Z]{16}\b
